# Using a Hangar as a Compass

![Using a Hangar as a Compass](https://commons.wikimedia.org/wiki/Special:FilePath/Loring_Arch_Interior.jpg)

A long building can act like a compass if the light is consistent. Stand still, read the ribs, and the whole span begins to point.

The hangar taught the same lesson as a shoreline: repeated structure can become direction. The trick is to give the reader a first fixed mark and then let the rest of the page behave predictably.

The note is here because Cartograph is not only for literal maps. It is for any page where orientation matters: a dense post list, a side rail, a route map, and a clean place for utilities.

When the coordinates fail, use the room.
