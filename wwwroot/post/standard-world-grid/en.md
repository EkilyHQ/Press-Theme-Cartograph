# The Standard World Grid at Desk Scale

![The Standard World Grid at Desk Scale](https://commons.wikimedia.org/wiki/Special:FilePath/Standard_map_of_the_World._LOC_00556407.jpg)

A gridded map does not ask to be admired first. It asks to be used. That is why it belongs in a Cartograph demo: the theme's rails, legends, and compact controls read like equipment rather than decoration.

I pinned four notes around the margin and treated each as a route: north for index cards, east for links, south for tags, west for the table of contents.

The page should feel like it can survive repeated checking. A map is a promise that the second reading will be faster.
